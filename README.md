# WarspearOnlineCalcDB

Source archive for WarspearOnlineCalcDB with installation instructions.

## Установка из репозитория

- Visual Studio с компонентами .NET Desktop / C++ согласно типу проекта.
- Откройте `BeastMasterCalc.sln`, восстановите NuGet и соберите решение; выберите стартовый проект для запуска.

```powershell
git clone https://github.com/Alangmat/BeastMasterCalc.git
cd BeastMasterCalc

```

Приватные настройки (.env, ключи и токены) создайте локально; используйте .env.example или другие example-файлы, если они есть. Указанные шаги сверены с файлами проекта; установка и запуск на чистой машине не проверены. Существующие разделы README содержат дополнительные требования к данным и окружению.
