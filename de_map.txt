[3] ПРИМЕНЕНИЕ РЕЗУЛЬТАТА — ApplyRecResult / ApplyRecResultCommand
  Строки: ~6317–6355
  _lastRounded: поле, куда сохраняется последний результат DE.
  ApplyRecResult(): записывает _lastRounded[0..10] → DataSet.*, вызывает Calculate().
  Кнопка активна только если _lastRounded != null.

[4] СОХРАНЕНИЕ В ФАЙЛ — SaveResults()
  Строки: ~6159–6305
  Пишет результаты в txt-лог (путь: AppData или рядом с exe).
  Содержит собственную копию весов (wSC..wSP) — СИНХРОНИЗИРОВАТЬ с [2].
  Вызывается тремя методами: gradient (~5618), mcts (~5924), de (~6146).

[5] ВСПОМОГАТЕЛЬНЫЕ МЕТОДЫ

  GetGuildStatBonuses(int level)      строки ~6405–6413
    Возвращает double[11] с бонусами гильдии.
    SC+15, ASp+15 при уровне >=10; CH+6, PA+6 при >=8; CD+20 при >=9; Ac+7 при >=11.
    SP всегда 0.

  ComputeRecBaseStats()               строки ~6420–6453
    Пересчитывает baseStats для отображения в UI (те же формулы что в DE).
    Учитывает: ветку, книги, гильдию, замковый дебаф (cFlat/cSP).
    Вызывается из RefreshRecBaseDisplay().

  RefreshRecBaseDisplay()             строки ~6461–6475
    Обновляет строки RecBase* для отображения "База" в UI рекомендаций.

  FormatDelta(double d)               строка ~6561
    "+X.X" или "-X.X" для отображения разницы стат.

[6] СВОЙСТВА — НАСТРОЙКИ РЕКОМЕНДАЦИЙ

  GuildLevel                          строка ~6382
    int 0..12. При изменении вызывает RefreshRecBaseDisplay().

  RecHasBook* (bool, 10 штук)         строки ~6386–6405
    RecHasBookSC, RecHasBookASp, RecHasBookCH, RecHasBookCD, RecHasBookP,
    RecHasBookAc, RecHasBookASt, RecHasBookPA, RecHasBookR, RecHasBookF.
    При изменении вызывают RefreshRecBaseDisplay().
    (Книги SP нет — SP-книга в игре отсутствует или не поддерживается.)

  UserMin* (double, 11 штук)          строки ~6489–6510
    UserMinSC, UserMinASp, UserMinCH, UserMinCD, UserMinP,
    UserMinAc, UserMinASt, UserMinPA, UserMinR, UserMinF, UserMinSP.
    Нижние границы для каждого стата при оптимизации.
    Defaults: UserMinCH=30, UserMinP=24, UserMinR=8.1; остальные=0.

[7] СВОЙСТВА — РЕЗУЛЬТАТЫ (binding для UI)

  Status (string)                     используется по всему файлу
    Статус-строка в нижней части UI.
